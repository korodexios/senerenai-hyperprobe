# Documentation Index

The root [`readme.md`](../readme.md) contains only the beginner path. The documents below contain the detailed operational reference.

| Document | Use it when |
|---|---|
| [`QUICK_START.md`](QUICK_START.md) | You are running the project for the first time or want the shortest setup path. |
| [`SETTINGS_AND_UPDATES.md`](SETTINGS_AND_UPDATES.md) | You need to understand the two settings files or update the project without losing local data. |
| [`SETTINGS_AND_WORKFLOWS.md`](SETTINGS_AND_WORKFLOWS.md) | You want to understand every main setting, sampler parameter, or preset mode. |
| [`SAMPLER_BENCHMARK.md`](SAMPLER_BENCHMARK.md) | You want the detailed Stage 1–3 design and handoff model. |
| [`REFUSAL_DATASETS.md`](REFUSAL_DATASETS.md) | You are preparing or validating a refusal JSONL dataset, especially Full mode. |
| [`NIAH.md`](NIAH.md) | You are preparing a long-context corpus and NIAH matrix. |
| [`RESULTS_AND_DASHBOARD.md`](RESULTS_AND_DASHBOARD.md) | You need to interpret records, run IDs, chains, or dashboard sections. |
| [`TROUBLESHOOTING.md`](TROUBLESHOOTING.md) | A command fails or the output is confusing. |
| [`LLM_SUPPORT_PROMPT.md`](LLM_SUPPORT_PROMPT.md) | You want another LLM to provide project-aware support. |
| [`LLM_REFUSAL_RESULT_REVIEW_PROMPT.md`](LLM_REFUSAL_RESULT_REVIEW_PROMPT.md) | You want another LLM to audit complete refusal replies row by row; provide it both the dataset and raw-output JSONL. |

The documentation is intentionally split by task. A beginner normally needs only `readme.md` and `QUICK_START.md`; advanced users can open the relevant reference page when needed.
