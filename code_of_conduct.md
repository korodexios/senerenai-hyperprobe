# Code of Conduct

Senerenai-HyperProbe is a public project intended to help people experiment with and evaluate language models. Everyone is welcome to ask questions, report problems, suggest improvements, and contribute changes.

Please be respectful, constructive, and specific. Critique code, documentation, prompts, and ideas rather than people. Do not post harassment, threats, discrimination, personal attacks, private information, or credentials.

If a discussion becomes difficult, step back and keep the focus on making the project more useful and safer. Maintainers may remove abusive content or restrict participation when necessary to keep the project usable for everyone.
